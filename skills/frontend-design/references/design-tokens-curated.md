## 2. TOP 10 CURATED COLOR PALETTES (WCAG AA Compliant)

### 1. Cold Luxury (Thay thế hoàn hảo cho Beige/Brass Slop)
- Background: `#0C0D0E` (Obsidian) hoặc `#F8F9FA` (Cold Chrome Light)
- Surface: `#16181A` (Dark) / `#FFFFFF` (Light)
- Text Primary: `#EDEDED` (Dark) / `#111213` (Light)
- Accent: `#38BDF8` (Electric Sky Blue) hoặc `#94A3B8` (Polished Steel)

### 2. High-Tech Cobalt (Tương phản cao B2B)
- Background: `#090D16` / `#F8FAFC`
- Surface: `#0F172A` / `#FFFFFF`
- Accent: `#2563EB` (Cobalt Blue, contrast ratio 7.2:1)
- Subtle Border: `rgba(255, 255, 255, 0.08)` / `rgba(15, 23, 42, 0.06)`

### 3. Emerald Minimalist (Sức khỏe / Năng lượng sạch / Đầu tư)
- Background: `#0B130E` / `#F7FAF8`
- Surface: `#122017` / `#FFFFFF`
- Accent: `#10B981` (Vibrant Emerald)
- Muted Text: `#6EE7B7` (20% opacity) / `#047857`

### 4. Crimson Terminal (Hệ thống bảo mật / DevTools hiệu năng cao)
- Background: `#0A0A0B` / `#FAFAFA`
- Surface: `#141416` / `#FFFFFF`
- Accent: `#F43F5E` (Laser Crimson)
- Border: `rgba(244, 63, 94, 0.2)`

### 5. Monochrome Architecture (Nghệ thuật & Kiến trúc tối giản)
- Background: `#FFFFFF` (Pure Light) hoặc `#000000` (Pitch Dark)
- Neutral Scale: Thang đo chuẩn Zinc (`#71717A`, `#A1A1AA`, `#E4E4E7`)
- Accent: Không dùng màu sắc sặc sỡ; tạo điểm nhấn bằng độ tương phản hình khối và độ dày font chữ.
